## Features  
  
* Automatically scan folders for games  
  
* Automatically fetch game information from multiple databases (currently supports [Bangumi](https://bgm.tv/) and [Visual Novel Database](https://vndb.org/)), and synchronize play status from your account  
  
* Sync game save files to the cloud (this feature requires any sync software on your PC to synchronize the save folder, such as OneDrive, NextCloud, Nutstore, Baidu Cloud Sync Disk, etc.)  
  
* Track and count playtime for games  
  
* Automatically extract games from archives and recognize/add them to your game library

## Translation  
  
PotatoVN uses Crowdin for localization. You are welcome to bring PotatoVN to your language on [Crowdin](https://crowdin.com/project/potatovn).  
  
## For developers  
  
This project is a WinUI 3 application. To build this project, please refer to the [Microsoft documentation](https://learn.microsoft.com/zh-cn/windows/apps/windows-app-sdk/set-up-your-development-environment?tabs=cs-vs-community%2Ccpp-vs-community%2Cvs-2022-17-1-a%2Cvs-2022-17-1-b)  
  
and install the corresponding development environment.  
  
This project uses the MVVM architecture and is developed on top of the framework generated by [TemplateStudio](https://github.com/microsoft/TemplateStudio/tree/main/docs/WinUI).  
  
Anyone interested is welcome to check the issues that are currently in urgent need of attention [here](https://github.com/GoldenPotato137/PotatoVN/discussions/categories/%E5%BC%80%E5%8F%91%E7%8A%B6%E6%80%81). PotatoVN is always happy to have you join~
